# 🌐 Ritik Sharma — Dual Domain Personal Portfolio

Welcome to the repository for my official personal portfolio website, deployed live on **GitHub Pages** and **Vercel**.

### 🔗 Live Demo: [portfolio-96.vercel.app](https://portfolio-96.vercel.app/)

## 🚀 Overview
This portfolio showcases my dual expertise in **Data Analytics** and **Electrical Engineering** (NIT Surat). Built using pure HTML5, modern CSS3, and ES6+ JavaScript for fast load times and clean UI animations.

## ✨ Key Features
- **Dual-Domain Navigation:** Interactive split landing page for Data Analytics and Electrical Engineering.
- **Interactive 3D Particles:** Custom HTML5 canvas particle background with smooth mouse interaction.
- **Dark / Light Mode:** Dynamic theme switcher with local storage persistence.
- **Live Inquiry Integration:** Integrated Web3Forms API to send contact submissions directly to email.
- **Responsive Design:** Optimized across desktop, tablet, and mobile displays.

## 🛠️ Tech Stack
- **Frontend:** HTML5, CSS3 (CSS Variables, Flexbox, Grid), JavaScript (ES6+)
- **Icons & Fonts:** Lucide Icons, Google Fonts (Outfit, Inter)
- **Form Backend:** Web3Forms API
- **Deployment:** GitHub Pages / Vercel
