AI-Powered News Automation

AI & Workflow Automation

An automated end-to-end news automation platform that collects news from Instagram and external news sources, analyzes and ranks stories using GenAI LLMs, generates viral headlines, summaries, captions, and hashtags, and automatically produces branded Instagram news posters. The system significantly eliminates manual effort in news discovery, content creation, graphics design, and social media publishing.

Python Google Gemini API Groq Apify NewsData.io GNews Guardian API Pillow (PIL) Instagram Graph API Telegram Bot API SQLite GitHub Actions REST APIs

✨ Key Features & Technical Architecture:

  • Multi-Source News Ingestion: Ingests news feeds from Instagram (via Apify) and external APIs including NewsData.io, GNews, Guardian API, and RSS feeds.
  • GenAI Story Processing: Integrates Google Gemini API & Groq LLMs to analyze, summarize, categorize, and rewrite news, generating catchy headlines, captions, and hashtags.
  • Dynamic Poster Generation: Creates publication-ready branded Instagram news posters programmatically using Python and Pillow (PIL).
  • Human-in-the-Loop Review & Publishing: Uses Telegram Bot API for instant content preview notifications and Instagram Graph API for publishing workflows.
  • Scheduled Automation: Orchestrates automated cron workflows using GitHub Actions and SQLite database storage for seamless automated operation.

SETU — Energy Supply Chain Analytics & Risk Intelligence Platform

Full Stack & API

An end-to-end data processing platform monitoring India's crude oil supply-chain risks. Built Python data ingestion pipelines for RSS feeds and official market data, exponential time-decay risk scoring algorithms, FastAPI REST APIs, and an interactive React dashboard with Leaflet world map and Recharts visualizations.

Python FastAPI PostgreSQL React.js Vite Leaflet Maps Recharts RSS Scrapers REST APIs

✨ Key Features & Technical Architecture:

  • Real-time News & Market Ingestion: Ingests crude oil supply-chain news, RSS feeds, and official market data using automated Python scrapers.
  • Time-Decay Risk Scoring: Evaluates geopolitical risk scores for energy shipping routes using customized exponential time-decay models.
  • Full-Stack REST Architecture: Powered by FastAPI & PostgreSQL database with robust endpoints for real-time risk analytics.
  • Geospatial Map Visualization: Features an interactive React + Leaflet dashboard visualizing global shipping bottlenecks, oil refineries, and risk zones.
